## 🌟 当前主力项目

### 1. TurboSync（Rust）—— 当前核心产品
**文件同步与协作工具**  
一个轻量、高效的 Rust 文件同步系统，专为协作场景设计。  
支持实时同步、冲突处理、权限控制，性能优于传统方案。

### 2. Keel（Python）—— 优雅后端脚手架
**让 FastAPI 开发像 DRF 一样高效**  
一个 DRF 风格的 FastAPI 脚手架，内置完整 CRUD、类型安全、智能过滤。  
让 API 开发效率提升数倍。

### 3. Rich-Utils（Python）—— 终端工程化工具集
**让终端输出像 Dashboard 一样清晰优雅**  
沉淀 Rich 能力为可复用组件，适配脚本、运维、压测等场景。  
结构化展示、进度控制、样式复用，工程友好。
